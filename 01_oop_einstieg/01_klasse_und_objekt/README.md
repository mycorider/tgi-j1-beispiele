# Klasse und Objekt mit TypeScript + p5.js

Dieses Beispiel zeigt, wie aus **einer Klasse** mehrere **Objekte** erzeugt werden.

## Lernziel

Nach diesem Beispiel kannst du:

- eine TypeScript-Klasse in einer eigenen Datei verwenden,
- mit `new` mehrere Objekte erzeugen,
- Objekten unterschiedliche Zustände geben,
- Methoden eines Objekts aufrufen,
- ein TypeScript-/p5.js-Projekt mit Vite starten.
