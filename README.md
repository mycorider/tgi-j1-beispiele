# TGI J1 – Unterrichtsbeispiele

Dieses Repository enthält Unterrichtsbeispiele für das Technische Gymnasium
Informationstechnik, Jahrgangsstufe 1.

## Schwerpunkte

- JavaScript
- TypeScript
- p5.js
- Objektorientierte Programmierung
- UML
- Datenbanken

## Verwendung

Repository aktualisieren:

    git pull

Bei TypeScript-/Vite-Projekten:

    npm install
    npm run dev
